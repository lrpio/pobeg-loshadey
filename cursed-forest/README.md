# 100 дней в Проклятом лесу

Игра на выживание по сценарию и голосовым запискам сына. Две версии:

- `browser_game.html` — браузерная версия: открыть в браузере двойным щелчком.
- `roblox/` — проект для Roblox (Luau + Rojo). Подробности в [roblox/README.md](roblox/README.md), содержание игры в [roblox/DESIGN.md](roblox/DESIGN.md).
- `place/CursedForest.rbxl` — собранное место: Roblox Studio → File → Open from File.
- `transcript_clean.md` — расшифровка голосового сообщения.

Проверки Roblox-проекта: `roblox/tools/check.sh` (нужны Rojo, Lune и Selene).
