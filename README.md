# Побег лошадей из конюшни

Мобильная игра для Android. Мальчик помогает трём лошадям сбежать из конюшни, пока смотрительница не видит.
В игре 5 маршрутов побега и 6 режимов сложности, от «Практики» до «Найт Мэр».

## Установка на телефон

1. На телефоне откройте раздел **Releases** этого репозитория и скачайте APK из последней версии.
   Репозиторий приватный, поэтому сначала войдите в свой аккаунт GitHub.
2. Откройте скачанный файл. Android попросит разрешить установку из этого источника: разрешите.
3. Если Google Play Защита предупредит о неизвестном приложении, нажмите «Всё равно установить».
   Приложение не запрашивает разрешений и не выходит в интернет.
4. Новая версия ставится поверх старой, удалять предыдущую не нужно.

На некоторых телефонах с китайской прошивкой (например, OPPO для Китая) установка APK из файла запрещена.
Тогда подключите телефон к компьютеру по USB и выполните `adb install -r <файл>.apk`.

Нужен Android 5.0 или новее.

## Версии

- **1.3**: больше укрытий в каждой комнате, куры во дворе, мыши и кошка в помещениях.
- **1.2**: текстуры больше не мерцают, мальчик и смотрительница обходят мебель, предметы не прячутся за мебелью.
- **1.1**: меню без прокрутки, порталы между соседними комнатами, комнаты больше и с оборудованием.

## Веб-версия

Файл `index.html` — вся игра одним файлом, открывается в браузере (нужен интернет для библиотеки three.js и шрифтов).

- Экран «Как играть» при первом запуске.
- Прогресс сохраняется в браузере: в меню появляется кнопка «Продолжить».
- Клавиатура: WASD или стрелки, E или Пробел (действие), Q (спрятаться), B (рюкзак), H (подсказка), M (звук), Esc (закрыть окно).
